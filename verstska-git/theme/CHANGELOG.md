# Changelog

## 0.2.0
- Front-page marketing copy now comes from WordPress content managed by the companion VERSTKADOC Content plugin.
- Added structured Service and Case content types, home-page fields, editable footer/site settings, and content-driven service/case cards.
- Preserved safe fallbacks so the theme still renders when the companion plugin is temporarily unavailable.
- Quote templates use the WordPress page title/content for editable introductory copy.
- Added single templates for services and cases.



## 0.1.0 — first WordPress conversion

- Converted the standalone VERSTKADOC prototype to a custom classic WordPress theme.
- Header navigation is centered on both desktop and mobile.
- Added editable WordPress Header Menu and Footer Menu locations.
- Added responsive mobile menu with Escape/outside-click close behavior.
- Added RU/EN locale-aware homepage copy and language links.
- Added front-page, page, single, archive, search and 404 templates.
- Added breadcrumb helper and reusable content template.
- Added basic RTL-aware article layout.
- Added `theme.json` for modern global/editor settings.
- Added Customizer settings for RU/EN site URLs and contact e-mail.
- Quote form markup is included, but mail delivery is deliberately not part of the theme yet.
