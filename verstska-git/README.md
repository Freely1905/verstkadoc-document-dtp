# VERSTKADOC — Document DTP

Source repository for the custom WordPress theme and content plugin used by the VERSTKADOC website.

## Repository layout

- `theme/` — VERSTKADOC Document DTP WordPress theme v0.2.0
- `plugin/` — VERSTKADOC Content plugin v0.1.0

## Important

Site content (pages, posts, services, cases, menus, media and database content) is maintained in WordPress and is intentionally not stored here.

The repository contains code and documentation only.
